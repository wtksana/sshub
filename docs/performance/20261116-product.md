# SSHub 正式产品性能与发行候选验收

日期：2026-11-16，Asia/Hong_Kong。此报告对应 P6 候选构建，首版整体仍有兼容性待补项，见[逐项验收](../specs/20261116-sshub-v1/acceptance.md)。

本机正式版本通过单终端空闲及八终端十分钟工作集目标。十次缓存首帧显示均小于一秒，但该计时不等于“启动到可操作”的端到端测量。持续负载中真实窗口的搜索、标签切换和分屏调整可用；未量化输入到显示延迟。

## 构建与环境

- Windows 11 家庭版中文版 10.0.26300；Intel Core Ultra X7 358H、16 个逻辑处理器、31.55 GiB RAM。同历史原型基线机器。
- Go 1.27.4 windows/amd64，MyGo v0.9.1，原生 UI；`mygo_nowebview,mygo_nodownload,mygo_noinspector`，CGO=0，正式构建无 automation。
- EXE SHA-256：`f3ab848f26fdc913dac6e4b3b35770fa41a4e266cebe66e0966f6dc43708d0d0`。构建从 `4c47f748cc8dc3c486ab7940b03a117ba94fbc1f` 加本轮未提交实现生成；构建信息的 `vcs.modified=true` 如实保留，不把打包时的 Git 提交当作编译来源。
- Ghostty DLL SHA-256：`53e8e2dd979702e8f2c48107af19be5a76efc2e88eb7cf1097218e899665da41`，与官方固定插件清单一致。八 SSH 会话期间检查进程模块，实际加载程序旁的 DLL。
- 1280×800 DIP，系统显示缩放约 150%，Cascadia Mono 13 DIP；每终端约 2 MiB 回滚，内联图片关闭。四个可见窗格，每窗格两个标签，共八个已连接终端；100 条已保存配置。
- 服务器为独立回环测试进程，临时密钥及固定测试公钥，未改用户信任记录。每会话每 20 ms 写 20 条、每条 101 字节，含 ANSI 绿色、中文“性能”、英文、编号、填充和 CRLF。四窗格下长行会折行。

## 测量与结果

进程工作集／私有提交量／CPU 每约一秒外部采样，CPU 的 100% 表示一个逻辑核。正式程序仅在 `SSHUB_DIAGNOSTICS` 显式启用时每秒输出接收字节、Go 堆、goroutine 和 ready/show 时间；不包含终端文本、目标或秘密。诊断开销包含在结果中。

| 场景 | 结果 | 目标与解释 |
| --- | --- | --- |
| 100 配置、十次缓存新进程启动 | 首帧显示平均 294.6 ms，最大 320.8 ms | 首帧显示小于 1 秒；可操作端到端计量待补 |
| 一个真实 SSH 终端、空闲约 15 秒 | 工作集平均 104.2 MiB，峰值 104.8 MiB | ≤120 MiB，通过本次短期空闲场景 |
| 同上 | 私有提交峰值 113.8 MiB；CPU 单核平均 5.74% | 不与工作集相加；含诊断及窗口刷新 |
| 八终端、约 601 秒持续输出 | 工作集平均 182.8 MiB，峰值 187.3 MiB | ≤300 MiB，通过本次十分钟场景 |
| 同上 | 私有提交峰值 193.9 MiB；CPU 单核平均 37.62% | 折算 16 逻辑核整机约 2.35%，非系统总 CPU |
| 接收量核对 | 外部采样差值 484,218,240 字节；平均每会话约 998.9 行/秒 | 外部时间和诊断时间有约一秒边界差；按诊断本身时间逐会话计算均约 1000.0 行/秒 |

接收计数在 SSH reader 处采集，表示管道已读取数据，不能据此声称逐行已绘制、帧率或渲染吞吐。逻辑行可能折为多行屏幕文本。

## 真实交互与发行检查

使用同一正式负载窗口进行以下检查，未借助调试版 automation 替代性能版本：四可见终端继续绘制；搜索输入“性能服务器-099”得到 1/100；切换后台标签后右侧服务器名称更新；拖动中央分屏从 x625 至 x710 后终端重排且持续输出。没有测输入到显示的硬件延迟，也未用字面中文输入替代输入法组合验收。

文件列表改为虚拟列表，2,000 条回环 SFTP 目录的真实窗口检查通过：首屏构建少于 100 行，滚动可达 `entry-1999.txt`；右键管理、新建、重命名、无权限、chmod 和删除确认继续通过。跨服务器上传目标绑定新增回归通过；磁盘满模拟保留原文件并清理 partial。目录读取仍整体保留条目，不能声称已对目录数据内存设硬上限。

Windows ZIP 包含 EXE、Ghostty DLL、使用说明、第三方许可、构建信息及逐文件／整包 SHA-256。解压校验全部文件后，在仅有 `C:\Windows\System32;C:\Windows` 的子进程 PATH 和独立 APPDATA 下运行：P5 旧程序、新包程序及更换程序目录后三次均正常退出，连接与主题配置哈希不变，信任文件未变，恢复标签／字号／侧栏保留，正式版本恢复连接数为零。未修改当前用户环境。此检查证明运行不需要 PATH 中的 Go／Node，不等同于无开发工具的全新虚拟机。

可复核发行检查摘要见 [release-summary.json](20261116-product/release-summary.json)。候选 ZIP：`build/releases/20261116-211354/SSHub-0.1.0-windows-amd64.zip`；SHA-256：`94956a6d5af750e0ba3f58dc0c6087150d450640b3e517024ce3169951a245f1`。后续重新打包的时间戳和 ZIP 哈希会不同，EXE 哈希必须单独核对。

## 比较、局限与复现

[历史原型](20261116-mygo-baseline.md)空闲工作集约 78.6 MiB，八终端 60 秒末段约 181 MiB；正式产品增加真实 SSH、配置库与文件面板，单终端峰值约 104.8 MiB，八终端十分钟峰值约 187.3 MiB。窗口尺寸、采样时长、负载生成位置和统计口径不同，不能将差值当作严格性能回归或跨框架比较。

本次保留系统缓存，不是重启冷启动；首帧 ready/show 不含硬件呈现，也不代表 SSH 提示符出现或网络握手。服务器与客户端在同机，未测真实网络、高时延／丢包、真实 OpenSSH／Unix 权限、vim/top、系统 IME、系统主题切换或小时级运行。未单独测 GPU 内存与帧时间。系统其他任务、电源和频率不受控；正式十分钟期间没有运行其他构建、Go 测试或另一应用验证窗口，仅编辑文档／脚本并作功能交互。单终端阶段有打包活动，空闲数据为短期结果。

```powershell
./scripts/build.ps1
./scripts/measure-startup.ps1
./scripts/measure-product.ps1 -SkipBuild -Sessions 1
./scripts/measure-product.ps1 -SkipBuild -Sessions 8 -Seconds 600
./scripts/package.ps1 -SkipBuild
./scripts/verify-release.ps1 -Archive <ZIP> -PreviousExecutable <旧版EXE>
```

测量脚本要求 PowerShell 7.5+；手动通过真实 UI 连接恢复标签后开始采样，不自动信任用户服务器。原始 [startup](20261116-product/startup/summary.json)、[idle](20261116-product/idle/summary.json)、[load-8](20261116-product/load-8/summary.json)、[分钟趋势](20261116-product/load-8/minute-trends.json)及同目录 CSV／诊断数据不包含测试私钥或用户终端文本。早先一次旧构建负载的汇总因 PowerShell 日期自动转换失败，其生成物保留在 artifacts，未混入本报告。
