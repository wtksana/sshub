# 日志高亮实施计划

状态：2026-11-17 四项任务已发布；01 基础高亮及 04 历史缓冲设置已实现并通过专项验证，02 依赖已解除，03 等待 02。依据[最终规格](spec.md)执行；综合正式负载验收尚未执行。

## 规格检查

核心行为与 Q22 及后续取消专门 JSON 高亮的要求一致。此次补齐以下验收歧义：

- 原生终端自带右键菜单，新增开关不能覆盖复制、粘贴、全选、清屏；第一条任务即验证接入。
- 刷新等待从首个待转发普通文本字节计时，不能因后续数据不断重置，也不能被底层阻塞读取拖住。
- 未完成控制串及普通文本均需有界；到预算后透传，不无限等待控制串终止符或文本边界。
- 空模式、零宽匹配、单词边界、配置编辑取消及保存失败的行为明确；含列表的规则配置不得通过共享可变数据意外生效。

当前不存在必须先做的独立重构。复用现有会话、设置与迁移流程；流式转换作为首条可运行功能的一部分验证，不先交付脱离用户流程的解析器框架。

## 已发布任务

### [01：在当前终端手动高亮日志级别](issues/01-terminal-log-levels.md)

Blocked by: None

交付：用户右键开启当前终端后，新增 TRACE／DEBUG／INFO／WARN／ERROR 等级别立即着色；关闭后后续输出恢复，旧颜色保留。这是第一个完整、可演示的功能。

验收重点：

- 菜单状态、键盘访问及原有编辑操作；两个会话隔离，新建／重连／重启默认关闭。
- 固定内置级别预设、单词边界、浅深主题及已有 ANSI 前景色优先。
- 中文／任意分块、有限等待后提示符可见、持续输入不饿死刷新、尾部数据及 EOF、关闭／取消／Resize 与原始接收计量。
- 基础预算与降级提示、未知控制内容透传、常见备用屏幕保护；必要安全及资源生命周期回归必须随本任务交付。
- 使用本地临时 SSH 的原生窗口验证菜单、着色、复制和搜索，先证明无需依赖补丁的接入可行。不能通过时记录阻塞，不继续堆设置功能。

### [02：在设置中配置内置级别与日期高亮](issues/02-built-in-highlight-settings.md)

Blocked by: 01

交付：用户能启停内置预设、修改颜色，并为新增输出启用常见日期／时间着色；保存、重启及配置迁移后规则保留。

验收重点：

- 旧配置缺少新字段时保留既有偏好并得到默认预设；颜色、开关随设置和迁移完整往返。
- 日期、时间、ISO 8601 代表性样本及级别优先于日期的冲突；颜色优先级沿用 01。
- 编辑取消、保存失败与外部修改不改变生效配置；后台使用一致的规则快照，不读取 UI 可变草稿。
- 保存成功只改变已启用会话的新增输出，不影响历史颜色及其他会话的开关；窄窗口和浅深主题可用。

### [03：配置自定义关键字与正则规则](issues/03-custom-highlight-rules.md)

Blocked by: 02

交付：用户在设置中新增、编辑、删除、启停及调整自定义规则顺序，用颜色突出日志中的业务关键词或模式。

验收重点：

- 普通关键字按片段匹配并支持大小写选项，正则使用 Go 语法；保存／导入前验证空模式、无效表达式、颜色和规则预算。
- 零宽匹配不插色；自定义规则按列表从上到下优先于内置级别和日期，局部重叠结果稳定。
- 规则内容、顺序和颜色完整保存及迁移；取消、失败和越界输入不部分应用，不损坏旧配置。
- 跨已输出边界允许漏色但不丢字，超长内容／大量匹配有界降级并提示，不阻塞输入及滚动。
- 独立终端开关、搜索及复制回归，端到端演示自定义规则保存前后的新增日志。
- JSON 日志作为普通文本测试，可通过关键字／正则突出字段名和业务值；不增加 JSON 语法解析、分类或预设。

### [04：配置终端历史缓冲档位](issues/04-scrollback-settings.md)

Blocked by: None

交付：用户在设置中选择 2／8／32／64 MiB 历史预算，保存后新建或重连终端使用新值，现有终端保持不变。

验收重点：

- 默认 2 MiB，旧配置回退，非法档位拒绝；设置、重启及配置迁移保持所选档位。
- 界面明确生效时机与非固定行数；已有会话及正在连接的会话采用创建尝试时捕获的档位，设置变更不重建终端。
- 对比修改前／后创建的两个终端，验证历史淘汰及重连行为；保存失败不改变生效值。
- 关闭高亮和开启高亮均使用同一缓冲设置。高亮未完成时可独立验证，不依赖 01–03。
