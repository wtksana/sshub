# 01：在当前终端手动高亮日志级别

## What to build

用户继续在现有 SSH 终端运行日志命令，通过右键菜单开启当前终端的日志高亮。新增日志级别使用内置浅深主题颜色，关闭后仅停止后续着色，已有历史颜色保留；其他终端不受影响。本任务交付第一条可运行的功能闭环，同时证明本地流式着色无需修改 MyGo 或远端环境。

## Acceptance criteria

- [x] 右键菜单显示“日志高亮”的开关状态，支持键盘访问，保留复制、粘贴、全选和清屏能力；实际验证终端自带菜单的接入，不假设父级菜单能覆盖它。
- [x] 新建、重连及重启恢复的终端默认关闭，不持久保存开关；切换标签保留当前会话状态，两个会话可独立开关。开启前的文本不补色，关闭不清除旧颜色。
- [x] 以固定预设支持 TRACE、DEBUG、INFO、WARN／WARNING、ERROR、FATAL／PANIC，忽略大小写，按 ASCII 字母／数字／下划线区分单词边界，固定 `error` 与 `errors` 的差异；内置颜色适配浅深主题，主题变化只影响新增着色。
- [x] 服务器已有显式 ANSI 前景色优先，仅对默认前景色补色；结束补色不清除原有背景、粗体等其他样式。切换开关不能使后续文本继承错误颜色。
- [x] 中文、UTF-8 及 ANSI 控制序列任意分块时不插坏编码或控制串。即使关闭高亮也能安全处理再次开启时的控制状态；未知／未完成控制内容保守透传，常见备用屏幕进入／退出有暂停保护，但不以此识别命令。
- [x] 从首个待转发普通文本字节计时，以约 20 ms 为额外等待的验证目标；后续字节不能不断推迟刷新，底层下一次读取未返回时已有无换行提示符仍能显示。跨已显示边界允许漏色，不丢弃文字或重写历史；记录测量方法，达不到目标时明确报告。
- [x] 等待、保留文本、控制串及输出扩张均有经测试确定的上限；超长或复杂内容仅跳过颜色并给出不刷屏的提示，不阻塞输入和滚动，不无限积累缓存。
- [x] 流式转换不记录输入、不推测命令，不修改 MyGo／Ghostty 或远端配置；保留输入、Resize、Close、取消及共享 SSH／SFTP 的资源所有权，诊断统计仍计原始接收字节。EOF、带数据错误及已接收尾部不会因转换结果分块而丢失，关闭能解除等待并回收后台任务。
- [x] 完成相称的流式、协议和生命周期回归；用独立数据目录、本地临时 SSH 与临时密钥进行原生窗口验证，覆盖开关隔离、连续日志、中文软折行、原有颜色、提示符、搜索及原文复制。关键兼容性若无法满足，记录阻塞后重新讨论，不继续扩展依赖本任务的设置功能。

## Answer

已实现本地流式日志级别着色及当前终端开关，不修改依赖与远端。正文右键使用透明子目标接收上下文请求，再通过 MyGo 公开原生菜单 roles 分发复制、粘贴、全选；原终端输入、鼠标选择和 IME handler 保留。Shift+F10／菜单键打开同一菜单，Ctrl+Shift+H 可直接切换；标签及窗格菜单也显示开关。

流式实现位于 `internal/connection/highlight.go`：普通文本最多缓存 16 KiB，单逻辑行超过 64 KiB 降级，控制串只保留至多 257 字节解析状态并持续原样转发；有界接收队列最多预留两个 16 KiB 块，关闭时排空已完成读取。固定预设只产生有限前景色 SGR，结束使用 39m；关闭高亮或已知无需着色时按块立即透传。每终端最多提示一次降级。后台读取配置只使用原子开关与主题，不读取 UI 状态。

验证：connection／desktop 原生标签 test、vet 通过；DebugBuild 成功。流式测试覆盖任意分块中文与控制序列、原色和其他样式、备用屏幕、实例隔离、EOF／带数据错误、阻塞提示符、持续输入 deadline、关闭与 Resize／Write 委托、100 次已排队和在途读取关闭回归、有界超长控制及文本。提示符以阻塞 io.Pipe 模拟 SSH 下一次 Read，单次刷新实测约 20.3–20.6 ms（目标 20 ms；测试允许调度误差，非发行延迟保证）。

原生窗口使用本次 worktree 的 DebugBuild、独立 `artifacts/log-highlighting-prototype/data`、本地临时 SSH／密钥及精确固定的 fixture 主机指纹。实际观察到：正文右键开关与勾选、INFO／ERROR 新增着色、Shift+F10 菜单、Ctrl+Shift+H 开启和关闭、历史颜色保留、左键聚焦与中文输入、全选、复制到临时搜索框保持原文、清屏。原生 popup 的键盘选项选择未由 CUA 成功驱动，快捷键已实测；不把该工具限制视作原生菜单本身支持的验证。
