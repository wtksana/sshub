# 04：配置终端历史缓冲档位

## What to build

用户在设置中选择 2／8／32／64 MiB 历史缓冲预算，保存后新建或重连的终端使用新值，已存在的终端保持不变。缓冲设置持久保存并支持配置迁移，不依赖日志高亮功能完成。

## Acceptance criteria

- [x] 设置提供 2／8／32／64 MiB 档位，默认 2 MiB；界面明确标注仅新建或重连终端生效，不承诺固定行数或与预算相同的进程内存，保留键盘及窄窗口可用性。
- [x] 保存成功影响之后发起的新建／重连尝试；正在连接的尝试使用开始时捕获的档位，已运行终端不改容量、不因设置变化重建或丢失现有历史。
- [x] 本地重启、导入导出保留所选档位；旧配置缺少该项时回退 2 MiB，保留已有偏好，非法档位在保存／导入前拒绝。
- [x] 编辑取消、保存失败和外部修改冲突不改变生效值、不部分覆盖旧配置，沿用既有配置写入及迁移保护。
- [x] 对比设置修改前后创建的两个终端，验证各自历史淘汰行为及重连后采用新档位；高亮尚未实现时可独立交付，高亮实现后也使用同一份缓冲设置。
- [x] 覆盖默认值、非法配置、持久化／迁移、失败及连接中切换设置的回归；在独立数据目录、本地临时 SSH 原生窗口验证设置说明、两会话差异和重连效果。对资源结果注明所选容量、负载及计量局限，不把保留行数作为固定 contract。
