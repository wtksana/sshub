# 02：在设置中配置内置级别与日期高亮

## What to build

用户在设置中启停内置日志级别和日期／时间预设、调整颜色，保存后影响所有已开启高亮终端的新增输出。规则全局共用并随偏好保存及迁移，终端开关仍独立且默认关闭。

## Acceptance criteria

- [ ] 设置提供内置日志级别及常见日期／时间规则的开关和颜色调整，适配浅深主题、键盘操作及窄窗口；不新增全局高亮开关或连接专属规则。
- [ ] 日期覆盖常见 YYYY-MM-DD、YYYY/MM/DD、时间及 ISO 8601 组合，以代表性样本固定边界。规则重叠时服务器显式前景色优先，其次日志级别、日期；不增加 JSON 预设或语法解析。
- [ ] 保存成功后全局规则作用于各已开启终端的新增输出，不改变历史颜色、终端开关或未开启会话；主题切换仅改变后续补色。
- [ ] 编辑草稿、取消和保存失败不改变当前生效规则；后台使用一致且不可被 UI 草稿修改的配置快照，不能读到半更新的规则。
- [ ] 规则开关和颜色在本地重启及导入导出后完整保留；旧配置缺失新字段时使用默认预设并保留已有偏好。无效颜色、非法或超限输入在保存／导入前拒绝，不部分应用。
- [ ] 配置写入、外部修改保护和迁移校验沿用现有机制，不能静默覆盖损坏数据或外部改动；终端开关不进入持久化或迁移数据。
- [ ] 覆盖默认值、保存／失败／取消、迁移、日期样本及规则冲突回归；在原生窗口演示设置保存前后新增日志的区别，核对历史、搜索和复制行为，复核相关流式预算及生命周期。
