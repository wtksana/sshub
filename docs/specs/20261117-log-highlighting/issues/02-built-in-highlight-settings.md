# 02：在设置中配置内置级别与日期高亮

## What to build

用户在设置中启停内置日志级别和日期／时间预设、调整颜色，保存后影响所有已开启高亮终端的新增输出。规则全局共用并随偏好保存及迁移，终端开关仍独立且默认关闭。

## Acceptance criteria

- [x] 设置提供内置日志级别及常见日期／时间规则的开关和颜色调整，适配浅深主题、键盘操作及窄窗口；不新增全局高亮开关或连接专属规则。
- [x] 日期覆盖常见 YYYY-MM-DD、YYYY/MM/DD、时间及 ISO 8601 组合，以代表性样本固定边界。规则重叠时服务器显式前景色优先，其次日志级别、日期；不增加 JSON 预设或语法解析。
- [x] 保存成功后全局规则作用于各已开启终端的新增输出，不改变历史颜色、终端开关或未开启会话；主题切换仅改变后续补色。
- [x] 编辑草稿、取消和保存失败不改变当前生效规则；后台使用一致且不可被 UI 草稿修改的配置快照，不能读到半更新的规则。
- [x] 规则开关和颜色在本地重启及导入导出后完整保留；旧配置缺失新字段时使用默认预设并保留已有偏好。无效颜色、非法或超限输入在保存／导入前拒绝，不部分应用。
- [x] 配置写入、外部修改保护和迁移校验沿用现有机制，不能静默覆盖损坏数据或外部改动；终端开关不进入持久化或迁移数据。
- [x] 覆盖默认值、保存／失败／取消、迁移、日期样本及规则冲突回归；在原生窗口演示设置保存前后新增日志的区别，核对历史、搜索和复制行为，复核相关流式预算及生命周期。

## Answer

- 设置中增加六组日志级别和日期／时间，共七项预设；逐项开关及浅深配色使用既有 Checkbox、ColorWell／ColorPicker 和有校验的 HEX 输入，不新增全局开关。缺少 `log_highlight` 字段时采用默认预设，显式全部关闭会稳定保存，未知／重复／缺失预设及无效颜色在共用配置校验中拒绝。
- 偏好集中 `Clone`，覆盖 Store 输入输出、迁移输入／私有预览／公开预览／提交、设置草稿及保存／应用边界。desktop 将持久化配置转换为 connection 的独立不可变规则快照，每次输出片段只读取一次；成功保存或导入后才更新所有当前流，不改终端开关或历史颜色。
- 日期按 ASCII 单词边界匹配年月日、时分秒、1–9 位小数及 ISO 时区组合；属于格式高亮，不做日历合法性验证。匹配优先级固定为级别、日期，服务器显式前景色仍优先。每个 16 KiB 片段的单规则收集上限为 1,024 个匹配，补色输出上限 64 KiB，超出则整片段保留原文并触发已有单次降级提示；自定义模式的复杂度与累计预算由 03 补齐。
- `go test -tags mygo_nowebview ./internal/library ./internal/connection ./internal/desktop`、相应 `go vet`、MyGo vet 与调试构建通过。测试覆盖全部关闭后的重启、迁移预览和存储副本所有权、无效保存／导入、外部修改保护、任意网络分块的日期样本、规则优先级、开关保持及草稿取消。补充了 ESC 重启 CSI、CAN／SUB 取消控制序列后显式前景色跨行保留的回归。
- 原生专项 `scripts/verify-highlight-settings-ui.ps1 -SkipBuild` 使用独立配置、本地 SSH fixture、临时密钥和精确固定的主机指纹，通过保存／取消／失败、键盘打开颜色选择器及实际选色、两会话隔离、隐藏标签主题更新、旧历史保色、连续 ANSI 输出、搜索、原文复制、迁移、重启与 900×620／字号 20。证据：`artifacts/highlight-settings-ui/20261117-220304/`，关键设置、历史和导入截图已查看。输入无效 HEX 草稿曾触发预览解析失败，现已修复安全预览并补回归。
