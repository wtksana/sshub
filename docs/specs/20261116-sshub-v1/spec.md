# SSHub 首版产品规划

状态：2026-11-16 整体方案已确认，P1–P3 已完成阶段验证，P4–P6 尚未实现。已验证范围与限制见 [P2](issues/03-secure-ssh.md) 和 [P3](issues/04-workspace.md)。

## 目标

开发启动快、资源占用低、交互流畅的 SSH / SFTP 桌面连接管理工具。开发由 AI 协助完成，不以用户已有技术经验限制方案。

沿用已经选定的 MyGo 原生 UI、官方 Ghostty 终端及 Go SSH / SFTP 技术方向。历史原型性能记录作为选型参考；原型代码已移除，正式产品需重新测量。

## 已确认范围

### Q1：平台

首版正式支持 Windows。保持代码的跨平台能力，macOS / Linux 后续单独验证与验收。

### Q2：定位与数据

面向单人使用，本地优先，无需注册账号。连接配置保存在本机，密码及口令使用系统凭据库。提供导入、导出；云同步、团队共享和权限管理暂缓。

凭据保存与导出规则见 Q12；首版不提供含凭据的备份包。

### Q3：主要工作流

SSH 终端为主，SFTP 与当前服务器联动。

典型流程：查找服务器 → 打开终端 → 执行命令 → 按需浏览、上传或下载文件。

首版不包含服务器监控面板、Docker 管理、数据库客户端和远程桌面。

### Q4：使用规模

以最多 100 条已保存连接、日常同时打开 2–8 个终端作为设计与验收场景。提供分组、搜索、收藏和最近使用。

上述数量是验收规模，不是产品硬性限制。

### Q5、Q10：主界面与会话组织

左侧为连接库，保留搜索和新建入口，收藏、最近使用及分组筛选收进菜单；中间只显示终端标签与终端内容，连接项管理和会话操作通过右键或标签栏“…”展开；右侧为文件面板。

标题栏与最小化、最大化／还原、关闭按钮由应用内置绘制，不显示系统标题栏；支持拖动和双击最大化，保留边缘缩放及在线退出确认。

左右侧栏可以收起并调整宽度。传输队列包含在右侧文件面板内，主窗口不设置独立底部传输栏。

一个标签代表一个终端会话，同一连接配置可以打开多个会话；文件面板跟随当前获得焦点的终端所在的服务器。每个分屏窗格有独立的标签组。

### Q6：认证与网络接入

支持密码、私钥、加密私钥、Windows OpenSSH Agent，以及单层 SSH 跳板机。多层跳板链、代理配置和完整 SSH config 兼容放到后续版本。

新建连接优先展示名称、地址、端口、用户名与认证方式，其他选项折叠到高级设置。

### Q7：文件管理

支持目录浏览、路径跳转、上传下载文件及文件夹、拖入上传、新建目录、重命名、删除、查看属性和修改权限；提供传输进度、取消与失败重试。

首版不内置代码编辑器，不自动同步目录；通过本地编辑器编辑远程文件放到后续版本。

### Q8：终端功能

支持标签切换、水平与垂直分屏、复制粘贴、终端内搜索、字体缩放，以及断线后手动重连。按最多四个可见窗格验收。

广播命令、脚本编排与命令片段库放到后续版本。

### Q9：视觉方向

采用接近 VS Code 信息密度的紧凑工具界面，减少装饰。支持浅色、深色与跟随系统，默认跟随系统。

界面默认简体中文，终端使用等宽字体；连接状态通过图标与文字共同表示。默认无动画，优先保证响应速度与可读性。

### Q11：分屏、关闭与恢复

每个分屏窗格有自己的标签组，每个标签对应一个终端会话。激活标签或聚焦另一个窗格时，右侧文件面板跟随该终端的服务器。

断线后保留当前窗口中的已有输出，允许手动重连。重连建立新会话，不能保证恢复先前的远程程序。

启动时恢复窗口布局与标签，但不自动发起网络连接。恢复标签不代表恢复 SSH 连接、终端输出或远程程序。

关闭在线会话或退出应用时提示确认；仍有未完成传输时额外提醒。

### Q12：凭据与导入导出

密码、私钥口令默认仅本次使用；勾选“记住”后才保存到系统凭据库。私钥引用本机文件，不复制到连接配置中。配置不得落盘明文密码或私钥口令。

首版导出连接配置、分组与偏好，不包含密码、私钥口令和私钥内容；不将系统凭据库引用当作可跨机器迁移的凭据。迁移后需要重新提供凭据，私钥路径需要重新核实。

导入先校验和预览，发生重名冲突时提供跳过、另存与替换选择。读取失败或内容不合法时不破坏已有配置。

### Q13：主机信任

首次连接展示地址、主机密钥类型与指纹，用户确认后保存信任记录；不得自动信任未知主机。

已保存的主机指纹发生变化时阻止连接，提示先核实服务器身份，再通过管理界面更新信任记录。跳板机与目标服务器分别校验。

### Q14：文件冲突、删除与失败

- 同名文件默认询问，可选覆盖、跳过、另存，并可应用到本批次。
- 删除前确认，明确远程删除通常无法撤销；不跟随符号链接递归删除。
- 首版失败重试从该文件开头重新传输，不提供断点续传。
- 取消或失败后清楚标明未完成文件，不显示为传输成功。
- 切换服务器不终止已有传输；右侧队列展示所有服务器的任务，并标明所属服务器。

### Q15：性能验收

在当前原型基线使用的电脑上，以正式构建、100 条已保存连接验收以下目标；它们是产品目标，并非当前版本已取得的结果。

| 场景 | 首版目标 |
| --- | --- |
| 系统已有缓存，启动到主界面可操作 | ≤ 1 秒，不等待网络连接 |
| 单终端空闲 | 应用进程工作集 ≤ 120 MiB |
| 8 个终端，每个持续接收 1,000 行/秒 | 运行 10 分钟，工作集 ≤ 300 MiB |
| 交互与稳定性 | 输入、切换、调整窗口无明显卡顿；持续负载后无持续内存增长趋势 |

重启后的冷启动单独测量，SSH 网络握手耗时单独记录。记录系统、硬件、分辨率、构建版本、行长度与内容、回滚容量、可见窗格数以及采样方法。八会话负载按最多四个可见窗格运行，其他会话保留在后台标签。

内存与 CPU 报告保留时间序列；不能仅依据十分钟未增长宣称不存在泄漏。输入接收速率不等于渲染吞吐；“无明显卡顿”需要真实窗口交互验证，不能只用构建耗时或数据管道吞吐替代。若自动化尚不能可靠测量输入到显示延迟，应明确记录局限。

### Q16：交付方式

先交付 Windows x64 ZIP 便携包，解压即可运行；用户机器无需安装 Go。便携包需包含运行所需的 Ghostty 动态库。

正式使用的配置默认保存在当前用户的数据目录；“便携包”指解压运行，不代表配置随程序目录迁移。首版手动更新，安装包与自动更新后续提供。

## 界面草图

```text
┌──────────────┬─────────────────────────┬──────────────────┐
│ 搜索 / 新建  │ 终端标签栏              │ 文件路径         │
│              ├─────────────────────────┤                  │
│ 收藏         │                         │ 远程文件列表     │
│ 最近使用     │       SSH 终端          │                  │
│ 服务器分组   │       / 分屏窗格        ├──────────────────┤
│              │                         │ 传输队列         │
└──────────────┴─────────────────────────┴──────────────────┘
```

传输队列的区域属于右侧文件面板，不跨越终端区域。

## 页面与状态

| 区域 | 内容与主要操作 | 必须表现的状态 |
| --- | --- | --- |
| 连接库 | 分组、收藏、最近使用、搜索，新建、编辑、删除及打开连接 | 无配置、无搜索结果、配置读取失败 |
| 连接编辑 | 名称、地址、端口、用户名、认证方式；折叠的高级设置包含跳板机 | 必填项错误、密钥不可读、保存失败 |
| 终端区 | 窗格标签、分屏、搜索、复制粘贴、缩放、手动重连 | 待连接、连接中、等待身份确认或凭据、已连接、已断线、失败 |
| 文件面板 | 路径、文件列表、导航、上传下载及文件操作 | 加载中、空目录、无权限、连接断开、操作失败 |
| 文件面板内的传输队列 | 全部服务器的任务、进度、速度、取消与重试 | 等待、传输中、等待冲突处理、成功、失败、已取消 |
| 设置与管理 | 主题、字体、导入导出、已信任主机管理 | 更改成功、读取或保存失败、导入冲突 |

连接、目录读取和传输不得阻塞主界面。错误应说明哪个服务器或文件、失败原因及可采取的下一步，不展示凭据内容。

## 已确认的收尾约定

1. 终端会话与传输任务的生命周期独立：关闭终端标签前提醒，但已确认继续的传输由任务队列持有连接直至完成；退出应用时选择返回应用继续传输，或取消传输并退出。
2. 修改或删除连接配置不改变已经建立的会话及已有传输；变更只影响下次连接。删除配置前说明仍有活动会话或任务，避免把删除配置误解为断开连接。
