# SSHub 首版规划地图

## Notes

采用 grilling 逐轮澄清，并在领域概念明确时更新术语表。2026-11-16 用户确认整体方案，进入 P1 实现。

## Decisions-so-far

- Q1：首版验收 Windows，其他平台后续单独验收。
- Q2：单人、本地优先；本机配置、系统凭据库、导入导出；暂缓云同步与团队功能。
- Q3：终端主导，SFTP 联动；不扩展监控、Docker、数据库及远程桌面。
- Q4：100 条连接配置、2–8 个同时打开的终端作为验收场景；提供分组、搜索、收藏、最近使用。
- Q5、Q10：左侧连接库、中间终端、右侧文件；传输队列包含在右侧文件面板内，无主窗口底部传输栏。一标签对应一终端会话，同一配置可开多个会话。
- Q6：密码、普通与加密私钥、Windows OpenSSH Agent、单层跳板机；暂缓多层跳板、代理配置与完整 SSH config 兼容。
- Q7：基础 SFTP 管理及文件夹传输，含权限、进度、取消、失败重试；暂缓内置编辑器、远程文件编辑和自动目录同步。
- Q8：标签、水平与垂直分屏、复制粘贴、终端搜索、缩放、手动重连；最多四个可见窗格验收，暂缓广播命令、编排与命令片段库。
- Q9：紧凑工具界面，中文、浅深主题及跟随系统，状态文字与图标，默认无动画。
- Q11：窗格有独立标签组，文件面板跟随焦点；断线保留当前输出，重连新建会话；启动恢复布局和标签，不自动连接；关闭在线会话、退出与未完成传输有提醒。
- Q12：密码与口令默认不记住，主动勾选后写系统凭据库；私钥只引用文件；导出不含凭据与私钥；导入冲突预览并选择处理。
- Q13：未知主机人工确认，指纹变化阻止连接，跳板与目标分别验证。
- Q14：同名默认询问；删除确认且不跟随符号链接递归删除；失败从单文件开头重试；未完成文件明确标记；切换服务器不影响任务，全局队列显示所属服务器。
- Q15：当前基线电脑上，100 条配置、缓存启动 ≤ 1 秒、单终端空闲工作集 ≤ 120 MiB、八终端每个 1,000 行/秒十分钟工作集 ≤ 300 MiB；交互与增长趋势需实测。
- Q16：Windows x64 ZIP 便携包，包含动态库，无需 Go；配置在用户数据目录，首版手动更新。
- Q17：整体方案与两项收尾约定均已确认；关闭终端可继续传输，修改或删除配置不影响已有会话及任务。
- P1 已完成：[01：应用骨架与连接库](issues/01-connection-library.md)，含真实 UI 与配置持久化验证；后续为 P2 安全 SSH 连接。
- 已按用户要求移除原型并拆分正式模块，Go、产品 UI 和正式构建验证通过；见 [02：项目结构](issues/02-project-structure.md) 及 [结构说明](../../architecture.md)。
- P2 已完成：[03：安全 SSH 连接](issues/03-secure-ssh.md)，覆盖密码／私钥／Agent／单层跳板、主机信任、系统凭据与真实终端；Go、产品 UI 和正式构建通过。交互程序、输入法及长期性能另行实测，下一阶段为 P3 工作区分屏与恢复。
- P3 已完成：[04：多会话工作区](issues/04-workspace.md)，覆盖四窗格八会话、独立标签组、焦点联动、搜索／字号、移动与合并、断网重连、布局恢复及坏文件保护；正常启动不恢复网络。下一阶段为 P4 SFTP 文件与传输。

- 按用户反馈简化界面：[05：简化工作区界面](issues/05-simplify-interface.md)，中间只保留标签与终端，连接管理与会话操作收进右键菜单，保留“…”及键盘入口；Go、三套真实窗口回归和正式构建通过。

- 按用户要求改为[06：应用内置标题栏](issues/06-custom-titlebar.md)：隐藏系统标题及按钮，支持拖动、窗口控制和边缘缩放；保留在线退出确认。窗口专项、三套功能回归及正式构建通过。

- P4 已实现：[07：SFTP 文件与传输](issues/07-sftp-files.md)，含异步文件浏览／管理、递归上传下载、全局队列、冲突、取消重试，以及关闭终端保留传输。受影响包 test／vet、SFTP 窗口专项和 SSH 生命周期回归通过；真实系统选择器及分离终端后的文件内容已核对。系统拖放、真实 OpenSSH、磁盘写满及跨服务器切换专项仍待补充，性能结论留待 P6。
