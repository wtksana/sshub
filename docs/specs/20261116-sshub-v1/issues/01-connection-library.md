# P1：应用骨架与连接库

## Scope

- 正式应用成为默认入口；保留 shell / idle / load / ssh 性能原型模式。
- 左连接库、中间待连接工作区、右文件面板，传输队列只在右侧内嵌。
- 配置增删改查、分组、搜索、收藏、最近使用与本机持久化。
- 不进行网络连接，不展示虚构的已连接状态或传输结果；实际 SSH 在 P2 接入。

## Design

- 配色：画布 #F5F7FA、面板 #FFFFFF、边线 #DCE2EA、正文 #263244、次要文字 #65748A、强调 #2763B3；跟随系统主题时采用框架对应色。
- 字体：Windows 界面使用 Microsoft YaHei UI；终端后续采用 Cascadia Mono。
- 布局：左栏约 260 DIP、右栏约 300 DIP，支持拖动分隔线与收起；中间填满剩余空间，文字与操作以左对齐为主。
- 遵循已确认的紧凑工具风格；无动画、无装饰性卡片网格，选中状态与清晰文本承担层次。
- 复核：不采用网页式大标题和概览数据卡；空白工作区提供新建操作，文件区说明需要先连接。

## Acceptance

- 新建、修改、删除、收藏和分组在重启后保留；删除前确认。
- 可搜索 100 条连接，按分组、收藏和最近使用筛选。
- “打开工作区”只打开待连接标签，记录配置最近使用，不自动连接网络。
- 损坏或不支持的配置不能被默认空配置覆盖；保存失败不改变内存中的已保存状态。
- 同数据目录的第二实例不能覆盖第一实例的配置；提供独立数据目录参数供隔离验证。
- 执行 Go 测试、vet、正式构建与真实 UI 自动化，验证中文、增删改查、筛选、重启及坏配置保护。
