# 简化工作区界面

## Scope

按用户反馈参考 VS Code：中间只显示标签与终端，移除连接详情、分屏工具条和常驻会话工具条；连接管理、会话与布局操作按对象放入右键菜单。搜索按需出现，保留状态、错误提示与安全确认。

## Design

沿用浅色底 #f5f7fa、正文 #263244、次级文字 #65748a、边界 #dce2ea、焦点 #2763b3；中文 Microsoft YaHei UI、终端 Cascadia Mono。紧凑标题栏、左侧连接列表、中间平面标签和终端、右侧文件及内嵌传输队列。标签以状态点、浅色选中底和细蓝线表达状态，避免多层工具栏及大片强调色。连接项双击连接，右键管理；标签右键操作会话与分屏，终端保留框架原有复制粘贴菜单。顶部菜单管理视图和主机信任；左栏筛选收进菜单。空状态只保留操作提示，非空终端让出全部高度。

## Acceptance

- 常态中间无连接详情和会话／分屏按钮；右键菜单和键盘入口可用。
- 连接配置编辑、收藏、删除、筛选以及多会话连接、分屏、搜索、缩放、移动、合并与恢复仍可用。
- 右键未选中的连接或标签时，操作准确作用于该对象；在线关闭与主机信任确认保留。
- Go test、vet、真实窗口回归、最小窗口和正式构建通过，检查界面截图。

## Answer

已移除中间连接详情、分屏工具条和会话工具条；每窗格只显示平面标签与终端，搜索按需展开。标签显示状态点，悬停提供地址、状态与字号，当前窗格用细蓝线标识。左栏双击连接，右键打开、编辑、收藏、忘记凭据或删除；标签右键或“…”操作连接、断开、搜索、字号、分屏、移动、合并及关闭。终端内部保留官方复制粘贴菜单，顶部只保留应用名和菜单入口；筛选收进左栏菜单并显示当前筛选摘要。

`Ctrl+Shift+Enter` 连接当前标签，`Ctrl+Shift+F` 搜索，`Ctrl+B` 与 `Ctrl+Shift+E` 切换侧栏。主机身份确认、凭据输入、错误提示和在线关闭确认保留。分屏、移动与合并先排队，完成当前渲染遍历再修改布局，修复菜单合并导致遍历失效的崩溃。
