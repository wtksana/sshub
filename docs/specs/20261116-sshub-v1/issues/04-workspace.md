# P3：多会话工作区

## Scope

- 每个终端窗格独立标签组，支持左右／上下分屏、移动标签与合并窗格；按四可见窗格、八会话验证，不将八会话作为硬限制。
- 当前窗格及终端焦点驱动右侧服务器状态；同配置的多个会话具有独立身份，关闭一个不影响其他会话。
- 终端搜索、上一处／下一处、字体缩放与重置，继续使用官方终端的复制粘贴与键盘处理。
- 恢复标签、布局比例、侧栏状态和终端字号；仅保存配置引用，不保存凭据、终端输出或网络状态，不自动连接。
- 保留断线输出，手动重连建立新会话；退出与关闭在线标签仍需确认。
- 布局坏文件、外部修改和写入失败保留原数据并明确提示。

## Design

沿用既有工具界面：背景 `#f5f7fa`、文字 `#263244`、次级文字 `#65748a`、边界 `#dce2ea`、焦点蓝 `#2763b3`。中文使用 Microsoft YaHei UI，终端使用 Cascadia Mono；不新增装饰与动画。将较高的连接详情压缩为紧凑信息条，为终端和分屏留出空间。蓝色边界仅标记当前窗格，标签、状态和操作靠左排列。

分屏创建空窗格，用户从连接库打开连接，或把已有标签移入；合并窗格仅移动标签，不断开会话。工作区模型与可靠存储放入独立 `internal/workspace`，协议与终端生命周期沿用现有模块。

## Acceptance

- Go 行为测试覆盖分屏、移动、关闭同配置会话、合并、恢复与坏文件保护。
- 实际窗口验证四窗格八会话、焦点与右栏联动、搜索与字号、关闭确认、重启不自动连接；沿用本地临时 SSH 服务。
- `gofmt`、`go test ./...`、`go vet ./...`、产品 UI 回归与正式构建通过，未测兼容性单独记录。

## Answer

已实现独立窗格标签组、左右／上下递归分屏、移动至下一窗格、合并当前窗格；蓝色边界标识当前窗格。四个可见窗格是当前限制，八会话为验收规模；标签文件另设 1024 条资源保护上限。同配置多个标签有独立会话 ID，移动和合并不重建网络连接，关闭只释放对应会话。

终端搜索复用 Ghostty 屏幕与回滚搜索，提供匹配数及上一处／下一处；`Ctrl+Shift+F` 打开搜索，Escape 关闭。工具栏与 Ctrl+滚轮调整每标签字号，范围 8–32，重置为 13。官方终端继续处理复制粘贴与远程键盘输入。当前终端的指针点击和实际焦点切换联动右栏服务器状态。

工作区写入独立 `workspace.json`，只保存分屏结构、标签 ID 和配置引用、各标签字号、侧栏状态、分隔比例与正常退出时窗口尺寸。UI 提交快照，后台 250 ms 合并写入、同步并替换，退出前刷新。恢复创建待连接标签，使用当前配置，跳过已删除配置，不恢复秘密、输出、SSH 或远程程序。文件损坏、版本不支持和外部修改均保留原文件并报错。

验证（Windows x64、Go 1.27.4、MyGo v0.9.1）：

- `gofmt`、`go test ./...`、`go vet ./...` 通过。
- 行为测试覆盖四窗格八标签、同配置标签关闭隔离、移动、合并、空窗格、无效操作不改状态、删除配置引用清理、严格布局校验、字号与偏好恢复、无网络恢复、损坏文件及外部改动保护。
- `verify-workspace-ui.ps1` 使用两台回环临时服务器建立八条真实 SSH 会话，逐会话验证标记输出可搜索；覆盖四窗格、点击／焦点联动、搜索、字号和重置、移动／合并、在线关闭确认与兄弟会话隔离。
- 同一窗口测试主动从服务器断开已有连接，验证旧输出仍可搜索；重连的终端旧标记消失、新服务欢迎输出可搜索。退出及重启后恢复标签、字号、分隔比例和侧栏状态，不出现真实终端或认证对话框；验证 900×620 最小窗口、正常退出尺寸、损坏布局与外部修改保护。
- `verify-library-ui.ps1` 与 `verify-ssh-ui.ps1` 的 P1／P2 回归通过，正式构建及原生窗口启动／退出检查通过。终端动态库仍随包分发。

限制：未新增长期负载与性能结论；中文输入法组合输入、vim/top 等交互程序及跨平台兼容性仍待专项实测。复制粘贴沿用框架能力，本轮未独立覆盖系统剪贴板内容往返。窗格拖动标签排序和任意拖放移动不在本阶段实现，使用明确移动按钮。SFTP 文件操作留在 P4。
