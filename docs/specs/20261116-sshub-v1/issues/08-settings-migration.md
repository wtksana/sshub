# P5：设置与迁移

## Scope

应用菜单内提供设置、导入与导出。支持浅色／深色／跟随系统、终端字体与默认字号；可靠保存偏好。导出连接、分组与偏好，导入严格校验并预览，同组重名逐项选择跳过、另存或替换。继续沿用已有主机信任管理，不导入信任或秘密。

## Acceptance

- 偏好保存后立即应用并可重启恢复，字号缩放与分屏布局继续有效。
- 导出只包含明确定义的配置字段与偏好，无密码、口令、私钥内容或系统凭据引用。
- 导入预览不写入；取消、损坏、重名未处理或保存失败均保留原配置。
- 一次提交全部连接及偏好；跳板引用正确重映射，导入不能自动继承已保存凭据。
- 编辑／替换配置不影响现有会话与传输快照；不自动发起连接。
- 按影响范围验证 library、desktop 及设置／迁移窗口。

## Answer

已实现 P5。设置、导入和导出均从应用菜单打开，中间工作区继续只显示标签与终端。

- 设置支持浅色、深色、跟随系统、终端字体和 8–32 默认字号，可靠保存后应用；默认保留标签缩放，提供显式统一重置。握手期间修改设置也会在终端接管时应用最新值。
- 独立导出白名单包含连接、分组、收藏和偏好，不包含秘密、凭据引用、主机信任、最近使用或布局；覆盖已有文件需要确认，应用管理的数据文件及其现存别名不可作为目标。
- 导入严格校验格式、大小、版本、未知字段、尾随数据、Unicode 同组重名及跳板图。预览不写入；冲突逐项跳过、另存或替换。绑定来源存储和文档快照，过期预览、外部修改、写入失败或无效图均不提交部分数据。
- 每个导入／替换项分配新 ID，隔离系统凭据；导入的私钥路径标记待核对，目标或跳板未确认时不发起网络。编辑后清除标记，现有标签仍保留旧快照，使用已确认配置需打开新工作区。
- 本地及导入跳板引用随替换重映射，保存的标签引用也映射至新配置；运行中的会话和任务仍使用原快照。布局独立可靠保存，不提供连接／布局跨文件事务。
- 主机信任管理继续复用 P2；导入不建立信任，也不自动连接。
