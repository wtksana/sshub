# P4：SFTP 文件与传输

## Scope

右侧文件面板接入异步浏览、路径跳转、右键管理和属性权限；实现文件及目录上传下载、拖入上传、全局串行队列、冲突决策、进度、取消与重试。任务绑定创建时的服务器及路径，关闭终端允许保留传输，退出需确认取消任务。

## Acceptance

- 中间保持标签与终端；队列只显示在右侧，操作主要放右键。
- 文件管理、错误、中文路径和递归传输通过本地隔离 SFTP 服务验证。
- 不跟随符号链接递归删除或传输；下载路径不能逃逸选定本地目录。
- 未完成内容写临时文件，失败或取消不显示成功；覆盖需确认，重试从头开始。
- 切换焦点及关闭终端不改变已创建任务目标；取消与退出释放资源。
- 按影响范围验证 connection、transfer 与生命周期及对应 UI，不默认全量回归。

## Comments

- 2026-11-16：开始实现；文件操作使用独立 SFTP 通道，传输持有共享 SSH 租约，与终端生命周期分离。

## Answer

已实现右侧异步文件浏览、目录导航及右键操作，涵盖上传／下载、目录传输、新建、重命名、删除确认与八进制权限。拖入上传绑定创建时的目录；队列仍在右侧，全局串行，提供字节数、当前文件百分比、平均速度、取消及从头重试。冲突支持覆盖、跳过、另存及批次策略。新文件按 600 权限写临时文件，覆盖保留原权限，成功后才发布；不跟随链接传输或递归删除。

终端及任务独立持有连接；关闭终端可继续传输，任务完成后释放最后引用。退出取消全部任务及短期文件操作；任务只存在于当前进程，启动不恢复。重试保留原配置／跳板及路径快照，原标签关闭后可重建标签并重新验证身份。

验证：

- 官方 automation 的 `verify-sftp-ui.ps1` 通过：浏览、新建、重命名、路径跳转、权限错误、chmod、删除确认；最后一次窗口记录在 `artifacts/sftp-ui/20261116-194905/`。
- 真实系统选择器验证中文文件上传下载且内容哈希一致，同名跳过、取消、原标签关闭后重连重试及另存通过。可控慢速回环服务验证 8 MiB 文件在终端关闭后继续完成，目标哈希一致；传输中退出提示及返回应用通过。记录在 `artifacts/sftp-ui/20261116-193431/` 和 `20261116-194241/`；这些是功能测试，不是性能采样。

- 已生成可直接运行的 Windows x64 正式构建：`build/windows-amd64/SSHub.exe`，同目录保留 `ghostty-vt.dll`；未把此次功能验证当作产品性能结论。

限制与待补验收：系统拖入上传、不同服务器焦点切换、真实 Windows／Linux OpenSSH SFTP、磁盘空间耗尽及长时间负载尚未实测。Windows 本地测试只验证 chmod 协议及可写属性，Unix 权限位需真实服务器进一步验证。远程服务器不支持 chmod 或原子覆盖扩展时明确失败；不会先删原文件。目录按文件提交，失败时可能保留已完成文件和目录，断网无法删除的 `.partial` 会报告路径。路径式 SFTP 操作不保证抵抗服务器上其他进程同时替换路径；当前不提供断点续传、符号链接复制或持久化任务队列。
