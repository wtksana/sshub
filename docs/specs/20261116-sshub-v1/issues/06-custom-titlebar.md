# 应用内置标题栏

## Scope

按用户要求移除系统窗口标题栏与系统窗口按钮，由应用绘制标题、菜单和最小化／最大化／还原／关闭按钮。中间继续只保留标签与终端。

## Design

沿用 #f5f7fa 背景、#263244 正文、#65748a 次级文字、#dce2ea 边界及 #2763b3 焦点，中文使用 Microsoft YaHei UI。顶部保持单层 34 DIP 高：左侧应用名和菜单、中间拖动留白、右侧三个无边框窗口按钮。关闭按钮悬停红色，按钮有中文辅助名称及提示。使用 MyGo 隐藏标题栏及按钮的模式保留系统阴影、圆角和缩放边缘，原生 UI 绘制全部内容，无 WebView。

## Acceptance

- 实际窗口无系统标题栏和系统绘制的窗口按钮，显示内置标题栏。
- 拖动、双击最大化／还原、最小化与恢复、边缘缩放可用；菜单和按钮可点击且不会误触拖动。
- 关闭按钮经过已有退出流程，在线会话仍确认；最大化／最小化退出不覆盖正常窗口尺寸。
- Go test、vet、实际窗口验证及正式构建通过，检查截图。

## Answer

已使用 MyGo `TitleBarHidden` 和 `HideWindowButtons` 移除系统标题栏及系统窗口按钮，保留阴影、圆角和窗口缩放边缘。`titlebar.go` 绘制单层 34 DIP 标题栏，应用名及留白可拖动，菜单和窗口按钮独立点击；关闭按钮悬停红色，所有按钮有中文辅助名称和提示。最大化按钮随状态切换为还原，并标记 `MaximizeButton` 接入 Windows 贴靠命中区域。

内置关闭按钮调用原有关闭流程，在线会话保留确认与取消。普通窗口尺寸在非最大化／非最小化时记录，最大化退出不会把显示器尺寸保存为下次的普通窗口尺寸。

验证环境：Windows x64、150% DPI、Go 1.27.4、MyGo v0.9.1。

- `gofmt`、`go test ./...`、`go vet ./...` 与 diff 检查通过。
- `verify-window-ui.ps1` 通过，结果 `artifacts/window-ui/20261116-191140`：Win32 检查窗口客户区顶部不存在系统标题栏空间，关闭按钮为客户区、最大化按钮提供贴靠命中区域、顶部边缘提供缩放命中；实际鼠标拖动窗口和顶部边缘缩放成功，最小化／恢复、双击最大化／还原、最大化／还原按钮、菜单及关闭按钮可用。最小尺寸 900×620、最大化退出和重启恢复普通尺寸通过；已目视检查截图。
- 连接库回归 `artifacts/library-ui/20261116-191036`、安全 SSH 回归 `artifacts/ssh-ui/20261116-191044`、工作区回归 `artifacts/workspace-ui/20261116-191051` 全部通过。安全 SSH 回归改用内置关闭按钮，验证在线退出取消和确认退出。
- 正式构建通过，PATH 排除 Go 后原生窗口启动、退出及布局保存通过。

原默认构建目录最初被用户打开的旧版占用，新增构建脚本 `-OutputDirectory` 和验证脚本 `-BuildDirectory`，先在 `build/titlebar/` 验证；未结束用户程序。旧版随后关闭，默认 `build/windows-amd64/SSHub.exe` 也已生成同版正式构建。

限制：本阶段验收 Windows；跨平台标题栏外观和系统贴靠弹出面板的交互尚未专项验证，贴靠验证覆盖 Windows 命中区域。
