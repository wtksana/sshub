# P2：安全 SSH 连接

## Scope

- 正式工作区异步连接 SSH，支持密码、普通与加密私钥、Windows OpenSSH Agent、单层跳板机。
- 未知主机显示指纹并等待明确确认，已知主机指纹变化拒绝连接；跳板与目标分别验证。
- 密码及口令默认仅本次使用，主动记住后写系统凭据库；支持忘记已保存凭据。
- 正式终端收发与 resize、连接取消、关闭及退出资源清理；保存配置与网络操作分离。
- 主机信任和凭据管理采用应用数据目录隔离；实际密码不进入配置或日志。

## Acceptance

- 本地临时 SSH 服务覆盖密码、加密私钥、Agent、跳板及主机信任错误路径，不连接真实服务器。
- 取消握手和等待确认后及时清理资源，失败可重试，认证信息不出现在快照和配置中。
- 主界面不等待网络或用户认证输入；终端显示真实输出。
- Go 测试、vet、产品 UI 回归、真实 SSH UI 自动化与正式构建通过；平台实测局限明确记录。

## Answer

已接入正式 MyGo 窗口与 Ghostty 终端，连接在后台运行，支持取消、断开、失败重试及关闭确认。工作区保存连接和跳板快照，断开保留输出，重连创建新终端与新 SSH 会话。终端回滚缓冲约 2 MiB，关闭内联图片，断开状态只显示在工具栏，避免注入提示覆盖远程输出。

支持密码、普通／加密私钥、Windows OpenSSH Agent 和单层跳板；配置校验阻止悬空引用、自引用、多层跳板及删除被引用的跳板。未知主机需确认 SHA256 指纹，变化密钥直接拒绝，跳板和目标分别核对。信任记录仅存当前应用目录，管理界面移除前再次确认。

密码与口令使用遮蔽字段，默认仅本次；明确勾选后在连接成功时写入系统凭据库，可忘记。凭据按数据目录、配置和认证目标隔离；配置文件、错误消息和 automation 快照不包含秘密，系统凭据库失败不回退明文文件。修改目标身份会使用不同凭据键；旧身份的凭据不会自动迁移。

验证（Windows x64、Go 1.27.4、MyGo v0.9.1）：

- `gofmt`、`go test ./...`、`go vet ./...` 通过。
- 协议测试通过：成功／错误密码、普通／加密私钥、错误口令、文件不存在、未知／变化密钥、拒绝确认、确认期间取消、损坏信任文件保留、忘记信任、取消握手、单层跳板及目标拒绝、多层跳板拒绝。
- Windows 命名管道 Agent 测试完成真实签名认证，并验证不可用路径；系统凭据测试验证读写删除、默认不保存、显式同意及数据目录／目标隔离。
- `verify-library-ui.ps1` 通过原有产品回归；`verify-ssh-ui.ps1` 通过真实窗口的指纹确认／取消、错误密码重试、秘密遮蔽、中文终端回显、面板调整、断开输出保留、跨重启凭据重用与忘记、信任移除、跳板加密私钥与退出确认。脚本仅连接本地临时 SSH 服务。
- 正式构建通过，EXE 约 14.2 MiB，随包 `ghostty-vt.dll` 约 2.1 MiB，其 SHA256 与固定版本官方插件清单一致；在 PATH 排除 Go 后启动原生窗口并正常退出。

限制：Agent 实测使用临时命名管道与真实 SSH 签名，并非已验证 Windows OpenSSH 系统服务配置；中文回显通过，但中文输入法组合输入、vim/top 等交互程序、生产服务器兼容性与长时间负载仍需后续验收。未宣称新的性能达标结果。分屏、恢复和 SFTP 文件操作尚未实现。
