原始证据在 `artifacts/sftp-ui/20261116-215219/`，无秘密结果为 [native-input-summary.json](20261116-native-input-summary.json)。`ime-committed.png` 已视觉核对，包含终端中文与一处搜索匹配。产品截图可能不包含系统候选浮窗；候选及组合过程另通过原生窗口状态实际观察。相关 SFTP 管理脚本正常结束，测试应用和临时服务器均退出。

## 正式版启动到可观察响应

新增 `scripts/measure-startup-interaction.ps1`，不修改产品，不在正式版加入调试 automation。每轮创建全新独立数据目录、100 条配置，不恢复布局或发起连接。启动前记录同一机器 UTC 时间，原生窗口出现后发送产品既有快捷键 `Ctrl+B`，获取窗口截图并实际核对左侧连接库已收起。截图调用完成时立即记录 UTC 时间，之后才写入核对结果。

此计量为“启动进程 → 已处理快捷键 → 截图观测完成”的保守上界，包含窗口发现、键盘自动化及截图开销。只要该上界小于一秒，就有证据说明该时刻界面已响应操作；不能把它称为精确的产品输入延迟或硬件呈现延迟。输入使用应用快捷键，不涉及终端命令。

EXE SHA256：`f3ab848f26fdc913dac6e4b3b35770fa41a4e266cebe66e0966f6dc43708d0d0`，与既有正式性能／候选包一致；本次未重新构建。

复现时先启动脚本，在每轮 15 秒准备期内使原生输入驱动等待新窗口；窗口出现后发送一次 `Ctrl+B`，抓取状态、记下截图完成时间并视觉核对，再将 `observation_completed_at`、`reviewed=true`、`sidebar_hidden=true` 写入对应 trial 目录的 `observation.json`。脚本会核对连接数、统计启动上界并正常关闭应用。不能在稍后核对时重新生成截图时间戳，也不能未经观察预填通过。仅脚本运行不会自动完成验收。

```powershell
./scripts/measure-startup-interaction.ps1
```
