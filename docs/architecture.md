# 项目结构

当前采用一个 Go module、一个桌面入口及按职责组织的内部包。根目录保留 `main.go` 与 `mygo.json`，符合现有 MyGo 构建方式；当前只有一个正式应用，入口无需额外迁移到 `cmd/`。

## 模块职责

| 位置 | 职责 |
| --- | --- |
| `main.go` | 解析 `-data-dir`，启动正式应用，报告启动错误 |
| `internal/desktop/window.go` | MyGo 应用生命周期和窗口创建；包对外提供 `Run` |
| `internal/desktop/diagnostics.go` | 默认关闭的正式性能诊断；首帧、接收字节与 Go 运行时计数，不读取终端文本 |
| `internal/desktop/app.go` | 界面状态及配置、收藏、最近使用等操作 |
| `internal/desktop/view.go` | 主布局、主题与全局反馈 |
| `internal/desktop/titlebar.go` | 内置标题栏、拖动区域和窗口按钮 |
| `internal/desktop/sidebar.go` | 连接库、搜索和筛选 |
| `internal/desktop/workspace.go` | 窗格树渲染、平面标签组、状态点及按需搜索 |
| `internal/desktop/layout.go` | 标签布局恢复、后台合并保存及退出刷新 |
| `internal/desktop/menus.go` | 连接项／标签右键菜单、窗格菜单、视图及筛选菜单 |
| `internal/desktop/settings.go`、`migration.go` | 设置应用、导入预览／冲突决策、导出覆盖确认及系统文件选择器 |
| `internal/desktop/terminal_tools.go` | 官方终端搜索与字号操作 |
| `internal/desktop/session.go` | 异步连接、终端生命周期、取消及断开 |
| `internal/desktop/prompts.go` | 串行主机确认与凭据输入提示 |
| `internal/desktop/credentials.go` | 系统凭据读写与连接身份隔离 |
| `internal/desktop/session_dialogs.go` | 关闭确认及主机信任管理 |
| `internal/desktop/editor.go` | 连接编辑表单、校验反馈及保存交互 |
| `internal/desktop/profile_groups.go` | 可输入的分组选择、右键改组与分组弹窗 |
| `internal/desktop/files.go` | 异步目录浏览、路径导航、文件右键与系统选择器 |
| `internal/desktop/file_dialogs.go` | 文件管理确认、属性权限与传输冲突决策 |
| `internal/desktop/transfers.go`、`transfer_view.go` | 全局串行队列、取消／重试及右侧进度呈现 |
| `internal/desktop/transport.go` | 终端、文件操作与任务共享 SSH 连接的生命周期 |
| `internal/library/profile.go` | 连接配置模型与字段校验 |
| `internal/library/filter.go` | 搜索、分组、收藏及最近使用筛选 |
| `internal/library/store.go` | 配置加载、CRUD、可靠写入和并发实例保护 |
| `internal/library/preferences.go`、`migration.go` | 偏好校验与可靠保存、迁移白名单、严格解码和原子批量导入 |
| `internal/library/lock_*.go` | 按系统选择文件锁实现 |
| `internal/workspace/` | 分屏树、标签引用、激活／移动／关闭／合并语义、严格校验与布局可靠写入 |
| `internal/connection/` | SSH 认证、取消、单层跳板、主机信任与终端通道；SFTP 底层能力及协议回归 |
| `internal/transfer/` | 文件树复制、批次冲突策略、进度及临时文件发布；不依赖 UI、不拥有 SSH 连接 |
| `internal/testssh/` | 共享的回环 SSH 测试服务；`cmd/` 只在 `e2e` 构建中提供 UI 测试辅助进程 |

拆文件用于集中每项职责，界面仍在同一包内；不为每个视觉区域创建额外包，也不增加只有转发作用的抽象层。

## 依赖与扩展

当前正式入口依赖 `desktop`，`desktop` 使用 `library`、`workspace` 与 `connection`；三个包均不依赖 UI。连接配置文件读写及数据目录锁由连接库处理；标签布局在同一锁的生命周期内读写独立布局文件，界面不自行解析或替换文件。测试服务不进入正式应用的依赖链。

P2 中 UI 负责操作、状态、终端实例与系统凭据集成；协议模块通过上下文和回调处理认证、握手、信任记录与远程通道。网络和凭据调用在后台执行，窗口更新统一派发到 UI 线程；每次连接有独立取消上下文与代次检查，过期结果不能覆盖新会话。连接标签持有连接配置及跳板配置快照，编辑保存不改变已打开会话的目标。

主机确认串行显示，避免并发会话覆盖提示。未知密钥仅在用户确认后可靠写入应用自己的 `known_hosts`；变化密钥拒绝连接。系统凭据按数据目录、配置及认证目标隔离，仅在明确勾选且连接成功后保存，失败不回退明文文件。

P3 将布局与运行中资源分开：`workspace.State` 只记录窗格、标签 ID、配置 ID 与展示偏好；`desktop.workspace` 按标签 ID 持有真实 SSH 连接、取消上下文和终端实例。移动或合并只改变标签归属，不释放连接；删除标签才释放对应资源。恢复根据配置 ID 读取当前配置并创建待连接状态，已删除配置不从布局复活。

布局写入使用独立 goroutine、容量一的最新快照队列和 250 ms 合并窗口，UI 只提交不可变编码快照；退出前刷新，随后释放数据目录锁。严格限制文件大小、版本、树结构、ID 唯一性和比例范围；坏文件与外部修改不会被静默覆盖。终端搜索仍由 Ghostty 完成，界面不复制输出到另一个搜索缓存。

窗口使用 `TitleBarHidden` 与 `HideWindowButtons` 隐藏系统标题与系统按钮，保留系统阴影、圆角及缩放边缘；标题栏由原生 UI 绘制，拖动交给框架，最大化按钮标记 Windows 贴靠命中区域。关闭按钮调用既有 `Window.Close` 流程，正常窗口尺寸只在非最小化、非最大化状态记录。

连接详情与常驻会话工具条已移除，管理动作绑定连接项或标签对象。终端内部保留官方复制粘贴菜单；应用菜单使用框架的窗口内菜单，与真实 UI 自动化共享行为。菜单回调发生在窗格渲染期间，分屏、移动与合并先排队，整棵树渲染及焦点处理结束后执行，避免遍历中改变树结构。

P4 中，`connection.OpenFiles(ctx)` 为每次浏览、管理操作和传输创建独立 SFTP 通道；取消先关闭该通道，等待服务器确认关闭。通道打开无法取消，或通道关闭超过 1 秒时，关闭该 SSH 连接及跳板连接，解除初始化、请求和清理阶段的阻塞；同连接的终端与其他文件操作会随之断开，其他服务器的排队任务可以继续。正常关闭仍保持通道隔离。UI 接管成功连接后停止握手取消钩子，改由共享连接引用管理：终端、短期文件操作、等待及执行中的任务各持有自己的引用，最后一个拥有者关闭 SSH 及跳板。关闭终端可以保留任务；应用退出取消任务和文件操作，并有界等待队列清理。

任务捕获创建时的配置／跳板快照与源、目标路径。后台串行 worker 处理队列，进度最多约每 150 ms 派发一次，界面只在传输期间定时刷新；冲突通过可取消的回复通道交回 UI。重试使用原快照，原标签已关闭时重新创建标签并走正常认证和主机校验。队列及任务历史只在本次进程内保存，启动不恢复传输。

传输模块使用本地 `os.Root` 与 SFTP 两种实际文件系统，逐项 Lstat 拒绝符号链接和特殊文件；下载检查名称并限制在所选本地目录内。删除独立实现、不跟随链接，拒绝根目录。单文件在目标目录写随机 `.partial` 后发布，覆盖远程文件要求 `posix-rename@openssh.com`；不先删原文件。目录逐文件提交，失败可保留已完成内容；断网无法清理的远程临时文件在错误中报告。SFTP v3 的路径操作无法消除远端并发替换造成的竞态，不声称提供服务器端文件系统事务。

P5 偏好与连接保存在同一文档，沿用锁、临时文件、同步与替换机制；旧文档无偏好时使用默认值。默认字号仅用于新标签和重置，已有字号由布局保存。字体应用到现有终端，握手期间捕获初始字体，UI 接管时再应用最新设置；主题以系统的当帧主题为基底，显式浅深选择覆盖它，Ghostty 跟随 UI 主题。

迁移格式用独立 `PortableProfile` 白名单，避免将运行期／本地认证字段随模型扩展意外导出。严格限制 8 MiB、版本、未知字段、尾随内容、重名及单层跳板图；预览保存来源存储及原文件快照，提交拒绝过期预览和外部改写。先在内存中计算全部结果，校验成功后单次可靠写入连接和可选偏好。

导入生成新配置身份，替换时重映射本地和导入连接的跳板引用，避免复用旧凭据。私钥路径仅作为待复核引用，目标及跳板均在发起网络前检查复核状态。保存的标签布局配置引用随替换映射更新，运行中的会话和任务仍持有原值快照；布局文件保持独立可靠写入，不声称与连接文件构成跨文件事务。导出经临时文件发布，不写入应用管理的数据文件或其现存硬链接／目录别名。

## 工具与资料

`scripts/` 保留正式构建、运行、产品 UI 验证、性能测量和便携包校验脚本。`automation.go` 是仅在 `e2e` 构建中启用的产品测试入口，保留用于真实窗口验证。正式构建不开放 automation；性能脚本通过显式 `SSHUB_DIAGNOSTICS` 输出路径启用容量一的后台诊断队列，每秒采样，不记录服务器、凭据或输出内容。诊断文件只允许新建，不覆盖已有文件。

文件列表只构建可见行，读取结果仍完整保留在当前标签中且有操作超时；不声称目录数据内存具有固定上限。传输等待通道容量 256，活动任务不因历史清理而移除；已结束任务只保留最近 256 条。终端各自约 2 MiB 回滚缓冲。

`docs/` 保存规格、实现状态、约定和可复核资料；`build/`、`artifacts/` 为被 Git 忽略的生成物。历史原型代码已移除，旧性能数据仍保留其环境与测量局限，不能用作当前版本的性能结果。

产品以连接标签承载终端会话，不再提供单独打开工作区的操作。内部 `workspace` 包仅保存窗格与标签布局；沿用 `workspace.json` 文件名以兼容已有数据。复制连接使用字段白名单，保存时分配新配置身份；分组变更基于最新保存的配置，不覆盖已有标签的配置快照。
