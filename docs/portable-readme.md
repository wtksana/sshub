# SSHub 0.1.0 候选版 · Windows x64

当前仍在首版验收，系统拖放、输入法及真实服务器兼容性等覆盖情况以仓库验收记录为准。

解压整个文件夹，双击 `SSHub.exe` 即可运行，无需安装 Go、Node 或 WebView2。`ghostty-vt.dll` 必须和 EXE 放在同一目录。当前实测 Windows 11 x64；其他平台尚未验收。

首次使用：左侧“+”添加连接，双击连接项建立会话。首次连接必须核对服务器指纹；指纹变化会阻止连接。密码和私钥口令默认仅本次使用，主动勾选后保存在 Windows 凭据管理器。私钥文件留在原路径，不复制进应用数据。

左侧连接和中间标签支持右键；标签栏“…”提供连接、断开、搜索、字号与分屏。右侧文件跟随当前终端，文件右键提供下载、重命名、权限和删除；“…”上传文件／文件夹，也可拖入本地内容。删除不可撤销，同名传输先确认。队列串行执行，支持取消、跳过、覆盖、另存和从头重试；关闭终端可选择继续传输。已结束任务仅保留最近 256 条。

顶部应用菜单提供主题、终端字体、配置导入导出、面板显隐与已信任主机管理。导出不包含密码、口令、私钥、凭据引用和主机信任；迁移后重新提供凭据，并在编辑连接中确认本机私钥路径。

快捷键：`Ctrl+Shift+Enter` 连接当前标签，`Ctrl+Shift+F` 搜索终端，`Ctrl+Shift+C`／`Ctrl+Shift+V` 复制／粘贴，`Ctrl+B` 显隐连接库，`Ctrl+Shift+E` 显隐文件面板，Ctrl+滚轮调整终端字号。

配置默认位于 `%APPDATA%\SSHub\`，不在程序目录。“便携”表示解压运行，配置不会自动随程序目录迁移。`connections.json` 保存连接和设置，`workspace.json` 保存布局和标签引用，`known_hosts` 保存已确认的主机身份。启动只恢复标签，不自动连接、不恢复远程程序或历史输出。可用 `SSHub.exe -data-dir D:\YourData` 指定独立数据目录，同一目录只允许一个实例。

手动更新：先正常退出应用，备份数据目录，解压新版本并保留 EXE 与对应 DLL，再运行新程序。不要用发行包覆盖用户数据目录。跨机器迁移使用应用内导出／导入；同机升级继续读取原目录。私钥路径、系统凭据及主机身份需要分别管理，不随 ZIP 分发。

若配置损坏，应用会显示错误并保留原文件；工作区损坏可先退出，将 `workspace.json` 改名备份后重启。操作时请依据服务器名称与路径核对目标。目录传输按文件完成，失败后已完成文件可能保留；未完成项使用 `.sshub-*.partial`，断网无法清理时错误会列出路径。

首版不提供断点续传、符号链接复制、持久化任务队列、多层跳板、远程编辑器、自动更新或云同步。路径式 SFTP 操作不能保证抵抗服务器上其他进程同时替换路径；不支持权限设置／原子覆盖扩展的服务器会明确失败，不先删除原文件绕过。

第三方许可保存在 `licenses/`，组件版本和 SHA-256 在 `build-info.json`，文件校验在 `SHA256SUMS.txt`。尚未数字签名。性能及兼容性验收以源码仓库中的首版报告为准，不能将单次通过理解为所有服务器和所有终端程序均已兼容。
